# Product

General description of what simple-canvas should do, and the problems it is intended to solve.

## Problem

I am a student at the University of Maryland, and the LMS used by UMD is Canvas, by Instructure. However, I dislike using the Canvas web application. My main complaint with the Canvas UI (and therefore UX) is that too much of the visual space is taken up by unnecessary features, which ends up obscuring the most important information, such as assignment deadlines and professor communications. To fix this problem, I would like to design a new interface for students to interact with Canvas that focuses on only the relevant details. However, I am not yet sure whether to make this as a Chrome extension or as a standalone app.
