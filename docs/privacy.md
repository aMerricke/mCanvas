# mCanvas Privacy Policy

**Effective date:** September 29, 2026

mCanvas is a browser extension that customizes the Canvas LMS interface and provides an assignment tracker.

## Data accessed

mCanvas accesses information from the Canvas LMS site where you are signed in, including course and assignment information. This access is used only to provide the extension's interface customization and assignment-tracking features.

## Data storage

mCanvas stores interface preferences and assignment completion state using Chrome local and sync storage. Temporary interface state may also be stored in browser session storage. Chrome may synchronize data saved in sync storage according to your browser settings.

## Data transmission and sharing

mCanvas communicates only with your current Canvas LMS instance using your existing signed-in session. It does not send data to the developer's servers, include analytics or advertising, sell personal information, or share data with third parties.

## Data retention and control

Stored data remains in your browser or Chrome account until you reset the relevant settings, clear the extension's data, or uninstall the extension. Data retained by Chrome synchronization is governed by your Chrome settings and Google's policies.

## Changes

This policy may be updated if mCanvas's data practices change. The effective date above will be revised when an update is published.

## Contact

Questions or concerns may be submitted through the [mCanvas GitHub repository](https://github.com/aMerricke/mCanvas/issues).
